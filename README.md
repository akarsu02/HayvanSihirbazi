# 🪄 Hayvan Sihirbazı

Hayvan Sihirbazı, çocukların çizdiği hayvanları yapay zekâ ile tanıyan, gerçek hayvan sesleri çalan ve eğitici bilgiler sunan interaktif bir uygulamadır.

## 🚀 Özellikler

- 🎨 Çizim alanı
- 🤖 Yapay zekâ ile hayvan tanıma
- 🔊 Gerçek hayvan sesleri
- ✨ Sihirli animasyonlar
- 📚 Eğitici hayvan bilgileri
- 📱 Mobil uyumlu tasarım
